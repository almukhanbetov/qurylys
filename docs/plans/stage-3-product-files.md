# Фото и документы товара: вариант решения (N5)

**Предложение, не решение.** ТЗ: фото — поле 06, сертификат/документ «при необходимости» — поле 21 (§06, с. 9); хранение S3-совместимое, срок доступа, антивирус (§03, с. 5).

Сейчас: контейнеры production только для чтения и без томов ([compose.prod.yml](../../deploy/compose.prod.yml)); файлы проверки компаний лежат в PostgreSQL и попадают в копию базы; антивируса нет; Nginx пропускает 6 МБ.

| Вопрос | Предложение |
|---|---|
| Хранение | PostgreSQL, отдельные таблицы: без новых сервисов, едино с копией базы. Перейти на S3, когда файлов станет больше нескольких ГБ |
| Фото | до 5 на карточку; JPEG/PNG до 5 МБ; проверка по содержимому и числу пикселей; **перекодирование** на сервере до 1600 px: удаляет EXIF и посторонние данные |
| Документы | PDF до 5 МБ, до 5 на карточку; только скачивание (`attachment`, `nosniff`, CSP `sandbox`) |
| Кто загружает | владелец — в заявке; модератор — в карточке. Продавец чужую карточку не меняет |
| Доступ | фото опубликованной карточки — всем, адрес по хэшу, долгий кэш; фото заявки — заявителю и модератору. Документы — по правилу ниже |
| Антивирус | фото: достаточно перекодирования. PDF: карантин, до чистого результата ClamAV (бесплатный, отдельный контейнер без внешнего доступа) файл не отдаётся никому, кроме загрузившего |
| Копии | входят в `pg_dump`; до внедрения оценить рост и место, восстановление проверять отдельно |
| Удаление | заменённое фото — физически; документ, на который опиралось решение, хранится для истории |

**Нужно решить:**

1. Принять ли хранение в PostgreSQL на этом этапе.
2. Хватит ли памяти VPS для ClamAV (ориентир 1–2 ГБ; на VPS не измерено). Если нет: этап выпускается с фото, а PDF — после появления антивируса.
3. Кому видны сертификаты: всем, вошедшим или только проверенным покупателям. Сертификат относится к карточке или к партии конкретного продавца.
4. Обязательно ли фото для одобрения карточки.
