# Приёмка этапа 3 «Кабинет поставщика»

Основание: [решения](../decisions/supplier-stage-3.md), [план](../plans/stage-3-supplier.md).

- Только **отдельный стенд** с тестовой базой и доставкой `CONTACT_DELIVERY=local`. Не production и не рабочая локальная база.
- Адреса `example.kz`, БИН, GTIN и компании — вымышленные. Пароли тестировщик задаёт сам и не записывает сюда.
- **[Сейчас]** — работает в `main` со сделанными 3.1–3.3 (A1–A8 — уже в `179f45c`). **[После 3.x]** — появится после шага плана; до этого тест **не пройден**, а не «пропущен».
- Названия будущих экранов и кнопок — проектные.

Коды подтверждения: `docker exec <контейнер-api> tail -n 3 /tmp/qurylys-outbox/outbox.jsonl`.
