# Этапы

Источник — ТЗ 1.0 от 17.11.2026. Стек, дизайн и способ авторизации — по решениям проекта (Go/Gin, Next.js, зелёная палитра, cookie-сессии), а не по §3–4 ТЗ.

> **Временное правило.** После одобрения компании Опт и Крупный опт открываются без оплаты. Платный доступ (ТЗ §12) не реализован; перед вводом тарифов правило согласуется отдельно.

## Этап 1 — регистрация и основа кабинета (опубликован)

Сделано, см. [accounts.md](accounts.md). Для первого запуска подтверждение только через email (решено 24.11.2026). SMTP-адаптер готов ([email.md](email.md)). Не хватает для запуска: настроенный ящик, HTTPS на домене, согласие на обработку данных.

## Этап 2 — верификация (текущий)

Сделано, см. [verification.md](verification.md). Одобрение пока только фиксирует результат: цены, товары и заказы от него не зависят. Осталось: спор о занятом БИН, MFA для MRX и администратора, антивирусная проверка файлов, срок хранения документов.

## Этап 3 — кабинет поставщика

- Выбор товара из общего каталога, своё предложение, публикация и скрытие (только одобренной компанией).
- РРЦ/Опт/Крупный опт с минимумами, единицы, упаковка, НДС, остаток, город; SKU и GTIN отдельно (BR-10).
- Партия, срок годности, документы — по категории (BR-11).
- Заявка на новый товар с модерацией.
- Решено 24.11.2026: `offers.price_tiyn` — это РРЦ. Опт и Крупный опт хранятся отдельно (новая миграция этапа 3), публичные запросы их не выбирают.
- Закрытые цены не выбирать из БД без права; персональные ответы — `no-store`; тесты на API, HTML и SSR-данные (BR-01, BR-02). Сейчас опт в БД не хранится, карточки анонимны.

## Этап 4 — покупка

- Корзина на каждого продавца; один заказ — один продавец (BR-05).
- Розница строго больше 50 000 ₸ (BR-03, BR-04); опт — минимум и кратность упаковки (BR-06, BR-07).
- Повторная проверка цены, минимума, упаковки, остатка в транзакции; snapshot в заказе; ключ идемпотентности.
- Обработка заказа поставщиком, история, уведомления, предупреждение безопасности (BR-15).
- Платформа не принимает оплату и не организует доставку.

Вне плана: ERP, бухгалтерия, WMS, логистика, тарифы.
